HTML (HyperText Markup Language) is used to create the structure of a website. It organizes content such as headings, paragraphs, images, links, and buttons.

SS (Cascading Style Sheets) is used to style a website. It controls colors, fonts, sizes, spacing, backgrounds, and the layout of elements.

JavaScript is a programming language that makes websites interactive. It allows you to create animations, respond to button clicks, validate forms, and update content dynamically.
